🛡 풀린 내용은 이 패널의 메모리에만 있습니다. 닫거나 10분 동안 쓰지 않으면 지워집니다.

도움말

  1. 드라이브 옆에서 보기: 구글 드라이브를 연 채로 도구 모음의 확장 프로그램 아이콘을 누르면 이 패널이 드라이브 옆에 열립니다. 드라이브에서 폴더를 열면 「📁 이 폴더」에 그 폴더의 암호화 파일이 보이고, 암호화 파일을 더블클릭해 미리보기를 열면 그 파일이 바로 선택됩니다.
  2. 보기: 목록에서 암호화된 파일을 고르고 비밀번호 또는 복구 키(35자)를 넣으면, 파일을 이 창의 메모리에서만 풀어 보여 줍니다. 한글(HWP·HWPX)·엑셀·워드·PDF·사진·CSV·TXT를 볼 수 있습니다. 한글·워드는 굵게·크기·색·정렬 같은 기본 모양만 보이며, 쪽 모양·그림·머리말은 다를 수 있습니다.
  3. 💾 저장: 지금 보는 파일을 암호 없이 다운로드 폴더에 저장합니다. 다 쓰면 휴지통에 버리고 비우세요.
  4. 🔒 고친 파일로 다시 암호화: 저장해서 고친 파일을 골라 새 보관 파일을 만들고 드라이브에 올립니다. 다시 풀어 비교하고, 올린 파일을 다시 받아 비교한 뒤에만 예전 파일을 휴지통으로 옮깁니다.
  5. ➕ 새 파일 암호화해 올리기: 컴퓨터의 파일을 바로 암호화해 내 드라이브 맨 위에 올립니다. 복구 키를 쓰면 데스크톱 앱에서도 열립니다.
  6. 지우기: 「닫기」, 탭 닫기, 10분 동안 쓰지 않으면 풀린 내용이 메모리에서 지워집니다.
  7. 안전: 구글 드라이브 API 주소에만 접속하고, 저장하는 것은 클라이언트 ID뿐입니다. 비밀번호·복구 키·파일 내용은 저장하지 않습니다. 운영체제의 스왑·화면 캡처는 막을 수 없습니다.
  8. 열리지 않을 때: 복구 키의 오타(0/O, 1/I, 8/B는 자동 처리)를 확인하세요. 아주 큰 파일(수백 MB)은 데스크톱 앱에서 푸세요.

이 확장 프로그램의 리디렉션 주소 (구글 콘솔의 웹 애플리케이션 클라이언트에 등록):

자동 잠금

개인 비밀번호 바꾸기 (잠금이 풀려 있을 때)

이 컴퓨터에서 열쇠 지우기

이 컴퓨터에 잠가 둔 복구 키를 지웁니다. 파일은 그대로이며 종이의 복구 키로 다시 설정할 수 있습니다.

🛟 처음 한 번 설정

모든 암호화 파일은 복구 키(만능키)로 잠급니다. 이 컴퓨터에는 복구 키를 개인 비밀번호로 잠가 보관하고, 평소에는 개인 비밀번호만 넣습니다.

새 복구 키입니다. 종이에 적어 안전한 곳에 두세요. 비밀번호를 잊거나 다른 컴퓨터에서 열 때 필요합니다. 이 화면을 닫으면 다시 볼 수 없습니다.

🔓 열림

    복구 키(만능키)로 잠그지 않은 예전 파일입니다. 이 파일을 잠글 때 정한 비밀번호를 넣으세요.

      1. 이 컴퓨터에서 고친 파일(또는 넣을 파일)을 고릅니다. 이름이 같은 파일은 바뀌고, 없는 이름은 추가됩니다.
      2. 새 보관 파일에 들어갈 내용을 확인합니다. (빼려면 체크)

      암호를 풀어 드라이브에 저장할까요?

      • 안의 파일이 원래 이름 그대로, 암호화 파일이 있던 같은 폴더에 생깁니다.
      • 풀린 파일은 암호가 없고, 그 폴더의 공유 설정을 따릅니다.
      • 올린 파일을 다시 받아 비교해서 모두 맞을 때만 암호화 파일을 휴지통으로 옮깁니다.

      풀린 파일을 이 컴퓨터에 저장할까요?

      • 암호가 없는 파일이 다운로드 폴더에 생깁니다. 누구나 열 수 있습니다.
      • 크롬 다운로드 목록에도 파일 이름이 남습니다.
      • 다 쓰면 파일을 휴지통에 버리고 휴지통도 비우세요. 공용 PC에서는 저장하지 마세요.
