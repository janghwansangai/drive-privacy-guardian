처음 한 번, 내 구글 프로젝트 만들기

개인정보 보안관은 내가 만든 로그인 열쇠로 구글에 로그인합니다. 그래서 파일과 로그인 정보가 내 컴퓨터 ↔ 구글 사이에서만 오가고, 개발자를 포함한 누구에게도 전달되지 않습니다.

⏱ 약 10분💳 무료 · 결제 정보 없음🔁 처음 한 번만

학교에서 관리자가 만든 클라이언트를 받았다면 이 안내는 건너뛰고 받은 값을 바로 넣으세요.
데스크톱 앱과 크롬 확장 프로그램을 둘 다 쓰면 같은 프로젝트 하나에 열쇠를 두 개(5-A, 5-B) 만들면 됩니다.

  1. 프로젝트 만들기

    구글 콘솔에서 열기 ↗
    1. 앱에서 쓸 구글 계정으로 로그인 (처음이면 약관 동의)
    2. 프로젝트 이름: 보안관-개인용 (아무 이름이나 괜찮음) → 만들기
    3. 화면 위쪽에 방금 만든 프로젝트가 선택됐는지 확인

  2. Google Drive API 켜기

    구글 콘솔에서 열기 ↗
    1. 사용(Enable) 버튼 누르기

  3. 앱 정보 입력

    Google 인증 플랫폼브랜딩

    구글 콘솔에서 열기 ↗
    1. "구성되지 않음"이 보이면 시작하기
    2. 앱 이름: 개인정보 보안관 (개인용)
    3. 사용자 지원 이메일 · 개발자 연락처: 내 이메일
    4. 사용자 유형(대상): 외부 → 동의 → 만들기

  4. 나를 테스트 사용자로 추가

    Google 인증 플랫폼대상테스트 사용자

    구글 콘솔에서 열기 ↗
    1. + 사용자 추가 → 로그인할 내 이메일 → 저장

    이걸 빠뜨리면 로그인할 때 "액세스 차단됨 · 403 access_denied"가 나옵니다.

  5. 로그인 열쇠(클라이언트) 만들기

    Google 인증 플랫폼클라이언트+ 클라이언트 만들기

    구글 콘솔에서 열기 ↗
    5-A

    데스크톱 앱용

    1. 애플리케이션 유형: 데스크톱 앱
    2. 이름: 보안관-데스크톱 → 만들기
    3. JSON 다운로드 → client_secret_….json 저장
    4. 앱 첫 화면 → 개인 설정 → JSON 파일 선택…
    5. 원본 파일을 휴지통으로 이동 → 휴지통도 비우기
    5-B

    크롬 확장 프로그램용

    1. 애플리케이션 유형: 웹 애플리케이션
    2. 이름: 보안관-확장
    3. 승인된 리디렉션 URI → + URI 추가 → 아래 주소 붙여 넣기
      https://gjlomabldjleleakkeffjojhjdgeekgj.chromiumapp.org/
    4. 만들기 → 클라이언트 ID만 복사 (보안 비밀번호는 필요 없음)
    5. 확장 프로그램 패널 → ⚙ 설정 → 클라이언트 ID 붙여 넣고 저장

    열쇠(JSON 파일·클라이언트 ID)는 남에게 보내거나 공유 드라이브에 올리지 마세요.

  6. 로그인

    1. 앱(또는 확장 프로그램)에서 로그인 → 계정 선택
    2. "Google에서 확인하지 않은 앱" → 고급 → (앱 이름)(으)로 이동 또는 계속
      내가 직접 만든 앱이라 구글 공개 심사를 받지 않아서 나오는 화면입니다. 정상입니다.
    3. 권한 화면에서 모든 항목 체크 → 계속

  7. (선택) 7일마다 다시 로그인하지 않게

    Google 인증 플랫폼대상앱 게시

    1. 테스트 상태에서는 구글 정책상 로그인이 7일 뒤 풀립니다.
    2. 앱 게시 → 확인하면 "프로덕션"이 되어 풀리지 않습니다. 나만 쓰는 열쇠라 인원 한도(100명)는 상관없습니다.
