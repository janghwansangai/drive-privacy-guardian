# 크롬 확장 프로그램 계획서 — 암호화된 파일 바로 보기

작성: 2026-09-26 · 상태: **E0·E1 완료, E2 구현 (사용자 확인 대기)** · 관련: SPEC.md, DECISIONS.md D-074(복구 키), D-078

## 1. 목표
데스크톱 앱으로 암호화한 보관 파일(`보관_날짜_xxxxxxxx.7z`)을, 앱을 켜지 않고 **크롬에서 바로 열어 보기**.

- 파일은 **메모리에서만** 풀어서 **확장 프로그램 전용 창**에만 보여 주고, 창을 닫으면 버립니다.
- "저장"을 눌렀을 때만 내 컴퓨터에 풀린 파일을 저장합니다.
- 고친 파일을 **다시 암호화해 드라이브에 올릴** 수 있습니다(앱과 같은 형식).

### 사용자 결정 (2026-09-26)
| 항목 | 결정 |
|---|---|
| 배포 | **무료** — Chrome 웹 스토어(5달러 등록비) 대신 GitHub Releases의 zip + **개발자 모드로 설치** |
| 우선 형식 | **한글(HWP·HWPX), 엑셀(XLSX)** |

## 2. 원칙 (데스크톱 앱과 같음)
1. **구글 외 통신 없음:** `host_permissions`를 `https://www.googleapis.com/*`(Drive API)로만 제한합니다. 로그인은 `chrome.identity`가 처리하며, 원격 코드·분석·오류 보고는 없습니다(Manifest V3는 원격 코드를 금지).
2. **원문 저장 없음:** 풀린 내용은 메모리(ArrayBuffer·Blob)에만 둡니다. 확장 프로그램 저장소, 디스크, 로그에 남기지 않습니다.
3. **비밀번호 보관 최소화:** 비밀번호나 복구 키는 입력해서 쓰고, 선택 시에만 `chrome.storage.session`에 둡니다(브라우저를 닫으면 삭제). `local`·`sync` 저장소에는 절대 두지 않습니다.
4. **영구 삭제 없음:** 다시 암호화할 때 원본 정리는 휴지통 이동만 하고, 앱과 같은 검증(풀어서 비교 + 업로드 재확인) 후에만 합니다.
5. **최소 권한:** `content_scripts` 없음(드라이브 페이지에 코드를 넣지 않음). `downloads` 권한은 "저장"에만 씁니다.

## 3. 구조
```
[확장 프로그램 창 (chrome-extension://…/viewer.html)]
  ├─ 로그인: chrome.identity (사용자가 만든 "Chrome 확장 프로그램" OAuth 클라이언트)
  ├─ 목록: Drive API files.list — 이름 규칙 `보관_YYYY-MM-DD_xxxxxxxx.7z|zip`
  ├─ 받기: files.get?alt=media → ArrayBuffer (메모리)
  ├─ 풀기: 7-Zip WebAssembly (메모리 파일 시스템) · AES-ZIP은 zip.js
  │     비밀번호 = 입력값 또는 복구 키 → HMAC-SHA512(키, 태그) (WebCrypto, 앱과 동일)
  ├─ 보기: 한글·엑셀·PDF·이미지·텍스트 뷰어 (전부 확장 프로그램에 포함, 오프라인)
  ├─ 저장: chrome.downloads (사용자가 누를 때만, 경고)
  └─ 다시 암호화: 7-Zip WASM으로 7z AES-256 + 헤더 암호화 → 검증 → files.create 업로드
```

- **다른 확장 프로그램이나 웹페이지는 이 창의 내용을 읽을 수 없습니다**(크롬의 확장 프로그램 격리).
- 7z 암호 해제에는 키 계산(SHA-256 반복)이 1초 안팎 걸립니다. WASM으로 충분히 가능한 수준입니다.

## 4. 형식별 보기 계획 (한글·엑셀 우선)
| 형식 | 방법 | 난이도 | 단계 |
|---|---|---|---|
| **XLSX** | 자체 해석기(zip + XML) → 시트별 표. 병합 셀·날짜 지원, 차트·그림 제외 (D-080) | 보통 | E1 |
| **HWPX** | zip + XML(OWPML) 직접 해석 → 문단·표·글자 모양(굵게·크기) 기본 | 보통 | E1 |
| **HWP 5.0** | 데스크톱 앱 파서(`dpg.core.extract.hwp`)의 레코드 해석을 TypeScript로 옮김 → 문단·표 텍스트. 한컴 공개 문서 표기 유지(D-048) | 높음 | E1은 글자·표, E3에서 모양 개선 |
| CSV·TXT | 표·텍스트 | 쉬움 | E1 |
| PDF | pdf.js(Apache-2.0)를 확장 프로그램 안에서 사용(크롬 기본 뷰어를 거치지 않아 파일로 남지 않음) | 쉬움 | E2 |
| 이미지 | `<img src=blob:>` (PNG·JPG·GIF·WEBP·BMP; SVG는 제외), 닫으면 URL 해제 | 쉬움 | E2 |
| DOCX | 자체 해석기(zip + XML) → 문단·표(가로·세로 병합). 의존성 없음 (D-082) | 보통 | E2 |
| 배포용·암호 걸린 한글 | "이 뷰어로 볼 수 없음" 안내 → 저장 후 한컴오피스로 | — | — |

**한계:** 한글 뷰어는 **내용 확인용**입니다. 쪽 모양, 그림, 머리말, 수식은 원본과 다르게 보이거나 빠질 수 있습니다. 정확한 모양이 필요하면 "저장" 후 한컴오피스로 여세요.

## 5. 무료 배포 방식 (개발자 모드)
1. GitHub Releases에 `DrivePrivacyGuardian-Extension-버전.zip`을 올립니다.
2. 사용자: 압축 풀기 → `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드** → 폴더 선택.
3. `manifest.json`의 `key`로 **확장 프로그램 ID를 고정**합니다(OAuth 클라이언트가 이 ID에 묶이므로 필수).

**알아 둘 점**
- 크롬이 가끔 "개발자 모드 확장 프로그램 사용 중지" 알림을 띄울 수 있습니다(무시 가능).
- **학교 관리 PC**는 관리자 정책으로 개발자 모드가 막혀 있을 수 있습니다. 그런 경우 개인 PC에서 쓰거나 관리자에게 허용을 요청해야 합니다.
- 자동 업데이트가 없어서, 새 버전은 zip을 다시 받아 폴더를 바꿉니다(데스크톱 앱과 같은 방식).

## 6. 구글 설정 (사용자가 한 번)
구글 콘솔(기존 프로젝트)에서 **사용자 인증 정보 → OAuth 클라이언트 ID → 애플리케이션 유형: Chrome 확장 프로그램 → 항목 ID(고정된 확장 프로그램 ID)**를 만들고, 클라이언트 ID를 확장 프로그램 설정 화면에 붙여 넣습니다. 안내 문서 `docs/EXTENSION_SETUP_KO.md`는 E1에서 작성합니다.

권한 범위: 보기 = `drive.readonly`, 다시 암호화·업로드까지 = `drive`. 데스크톱 앱처럼 필요할 때 단계적으로 요청합니다. (`drive.file`은 앱이 만든 파일만 보여 줘서 데스크톱 앱이 만든 보관 파일이 안 보일 수 있으므로, E0에서 확인)

## 7. 단계
| 단계 | 내용 | 완료 기준 |
|---|---|---|
| **E0 검증** | ① 7-Zip WASM 라이선스(LGPL, **RAR 해제 코드 제외 빌드** 필요 여부) ② 개발자 모드 + 고정 ID로 `chrome.identity` 로그인 ③ Drive 권한 범위 ④ SheetJS·pdf.js·zip.js 라이선스 ⑤ MV3 CSP에서 WASM 실행(`wasm-unsafe-eval`) | DECISIONS.md에 출처와 함께 기록 |
| **E1 보기** | 로그인 → 🔐 암호화된 파일 목록 → 비밀번호·복구 키 → 메모리 복호화 → **XLSX·HWPX·HWP(글자·표)·CSV·TXT** 보기, 창을 닫으면 폐기 | 앱이 만든 7z·AES-ZIP·복구 키 파일을 모두 열 수 있음(합성 데이터 테스트). 디스크·확장 프로그램 저장소에 원문 0건 |
| **E2 저장·형식 확장** | "저장" 버튼(경고 창, `downloads` 권한 없이 한 번짜리 다운로드 링크), PDF·이미지·DOCX 보기 | 저장은 누를 때만. 뷰어는 전부 오프라인 |
| **E3 다시 암호화** | 파일 선택 → 7z AES-256+헤더 암호화(복구 키 규칙) → 풀어서 비교 → 업로드 → 재확인 → (선택) 원본 휴지통 | 데스크톱 앱이 이 파일을 그대로 풀 수 있음 (상호 호환 테스트) |
| **E4 다듬기** | HWP 글자 모양·표 모양 개선, 대용량(100MB+) 처리, 한국어 안내 | 사용자 확인 |

## 8. 테스트 방침
- 합성 데이터만 사용합니다(`tools/gen_synthetic.py` 출력). 데스크톱 앱으로 만든 보관 파일을 확장 프로그램 테스트 입력으로 씁니다(**상호 호환 테스트**).
- 가짜 Drive API(목 서버 없이 `fetch` 대체)로 네트워크 없이 테스트합니다.
- 원문 유출 검사: 테스트 후 확장 프로그램 저장소(`chrome.storage.*`)와 다운로드 폴더에 원문 패턴이 0건이어야 합니다.
- 실제 계정 확인은 사용자가 테스트 계정으로 하고, 결과는 통과·실패만 받습니다.

## 9. 위험과 대응
| 위험 | 대응 |
|---|---|
| 확장 프로그램이 공격 대상이 됨 | 콘텐츠 스크립트 없음, 권한 최소화, 원격 코드 없음, 의존성 고정·라이선스 검사, gitleaks |
| "메모리에서만"의 한계 | 스왑·화면 캡처·충돌 기록은 막을 수 없음. 창을 닫으면 참조를 해제하고, 일정 시간 입력이 없으면 자동으로 닫기 |
| 한글 뷰어 품질 | "내용 확인용"이라고 표시하고, 정확한 모양은 저장 후 한컴오피스로 |
| 개발자 모드가 막힌 학교 PC | 안내 문서에 명시하고, 데스크톱 앱을 대안으로 |
