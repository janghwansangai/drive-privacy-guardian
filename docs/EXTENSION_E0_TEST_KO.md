# 확장 프로그램 E0 시험 방법 (테스트 계정으로)

> ✅ 2026-09-27 완료. 시험용 확장 프로그램(`extension/probe`)은 정식 버전 `extension/app`으로 대체되어 삭제했습니다. 설치·사용은 [EXTENSION_SETUP_KO.md](EXTENSION_SETUP_KO.md).

확인하는 것 세 가지: ① 확장 프로그램에서 구글 로그인이 되는지 ② **가장 좁은 권한(drive.file)**으로 앱이 만든 암호화 파일이 보이는지 ③ 7-Zip이 브라우저 안에서 도는지.
드라이브는 **읽기만** 하고, 파일 내용은 받지 않습니다.

## 1단계. 구글 콘솔에서 확장 프로그램용 클라이언트 만들기 (5분)
데스크톱 앱에 쓰는 **같은 프로젝트**에서 합니다.
1. https://console.cloud.google.com/apis/credentials 접속 → 위쪽에서 데스크톱 앱과 같은 프로젝트가 선택됐는지 확인
2. **+ 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
3. 애플리케이션 유형: **웹 애플리케이션** (데스크톱 앱이 아님)
4. 이름: `DPG 확장 프로그램`
5. **승인된 리디렉션 URI → + URI 추가**에 아래 주소를 그대로 붙여 넣기
   ```
   https://gjlomabldjleleakkeffjojhjdgeekgj.chromiumapp.org/
   ```
   (끝의 `/`까지 포함. 「승인된 자바스크립트 원본」은 비워 둡니다)
6. **만들기** → 나오는 창에서 **클라이언트 ID**만 복사해 둡니다.
   - "클라이언트 보안 비밀번호"는 **쓰지 않습니다.** 어디에도 붙여 넣지 마세요.

## 2단계. 크롬에 시험용 확장 프로그램 설치
1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** → 이 폴더를 선택:
   `drive-privacy-guardian/extension/probe`
4. 목록에 **"Drive Privacy Guardian — E0 시험"**이 생기고, ID가 **`gjlomabldjleleakkeffjojhjdgeekgj`**인지 확인합니다.

## 3단계. 시험하기
1. 크롬 오른쪽 위 **퍼즐 아이콘(🧩) → "Drive Privacy Guardian — E0 시험"** 클릭 → 시험 탭이 열립니다.
2. **①** 칸에 1단계의 클라이언트 ID를 붙여 넣고 **저장**
3. **②** 「실행」 → "✓ 7-Zip WASM 동작"이 나오는지 봅니다.
4. **③** 「로그인하고 찾기」 → **테스트 계정** 선택 → 'Google에서 확인하지 않은 앱' → **「계속」** → 권한 체크 → **「계속」**
   → "✓ 로그인 성공 · 찾은 암호화 파일 N개"
5. ③에서 **0개**가 나오면 **④**도 해 봅니다(넓은 권한).

## 4단계. 결과 알려 주기
아래처럼 **성공/실패와 개수만** 알려 주세요. 클라이언트 ID·파일 이름·화면의 긴 값은 붙여 넣지 마세요.
```
② 성공/실패
③ 성공/실패, 개수: ?
④ (했다면) 성공/실패, 개수: ?
참고: 앱에서 보이던 🔐 암호화된 파일 개수: ?
```

## 끝나면
시험용 확장 프로그램은 `chrome://extensions`에서 **삭제**해도 됩니다(다음 단계에서 정식 버전을 드립니다). 구글 계정 → 보안 → 타사 앱 연결에서 "DPG 확장 프로그램" 권한도 지울 수 있습니다.
