# 개인정보 보안관 (Drive Privacy Guardian) 사용 안내

구글 드라이브의 **공유 권한**과 **개인정보가 든 파일**을 내 컴퓨터 안에서만 점검하고, 필요하면 공유를 줄이거나 암호화해 보관하는 프로그램입니다. 설치 방법은 [INSTALL_KO.md](INSTALL_KO.md)를 보세요.

## 0. 약속
- 데이터는 **내 컴퓨터 ↔ 구글 서버** 사이에서만 오갑니다. 개발자 서버·원격 분석·외부 AI가 없습니다.
- 찾은 개인정보의 **원문은 저장하지 않습니다**(유형·건수·위치만).
- 드라이브를 바꾸는 일은 모두 **미리보기 → 승인** 후에만 하고, 되돌릴 수 있습니다. **영구 삭제 기능은 없습니다**(휴지통 이동만, 30일 안에 복원 가능).

## 1. 처음 실행 — 설정과 로그인

1. 앱을 실행하면 **설정 마법사**가 열립니다. **개인 설정** 또는 **학교에서 받은 파일이 있음**을 고릅니다.
   - 개인 설정은 구글 콘솔에서 내 전용 OAuth 클라이언트를 만듭니다: [SETUP_GOOGLE_KO.md](SETUP_GOOGLE_KO.md)
   - 학교 관리자용: [ADMIN_SETUP_KO.md](ADMIN_SETUP_KO.md)
2. **JSON 파일 선택…**으로 내려받은 클라이언트 파일을 불러온 뒤, 안내대로 원본 파일을 휴지통으로 옮기고 비웁니다.
3. **구글 로그인**을 누르면 브라우저가 열립니다. 화면의 파란 상자 순서대로 진행하세요.
   1. 구글 계정 선택
   2. **'Google에서 확인하지 않은 앱'** → **「계속」** (없으면 「고급」 → '앱 이름으로 이동'). 직접 만든 앱이라 심사를 받지 않았을 뿐입니다.
   3. 권한 화면에서 **모든 항목 체크 → 「계속」**
   4. '로그인 완료' 페이지가 보이면 탭을 닫고 앱으로 돌아옵니다.
4. 로그아웃은 오른쪽 위 **로그아웃**. 로그아웃하면 버튼이 **🔑 로그인**으로 바뀌어 바로 다시 로그인할 수 있습니다.

## 2. 화면 구성 — ① → ④ 순서로

| 구역 | 하는 일 |
|---|---|
| **① 검사하기** | 어디를 검사할지 고르고 **▶ 검사 시작**. "개인정보도 찾기"를 체크하면 파일 내용까지 검사 |
| **② 결과 요약** | 칸을 누르면 그 파일만 ③에 보임 (전체·긴급·개인정보·링크 공개·외부 공유·도메인 공개·확인 필요·🙈 탐지 제외·🔐 암호화된 파일) |
| **③ 파일 목록** | 왼쪽 **체크박스**로 파일을 고름. 맨 위 체크박스는 보이는 파일 모두 고르기/해제 |
| **④ 고른 파일로 할 일** | 공유 설정 바꾸기 · 암호화 보관 · 폴더로 옮기기 · 내용 확인 · 탐지에서 제외 · 보관 파일 풀기 |

- 다른 칸에서 체크해 둔 파일이 지금 안 보이면 ④에 "⚠ 다른 보기에서 고른 파일"이라고 알려 줍니다. **모든 체크 해제 (다른 보기 포함)**로 한 번에 풀 수 있습니다.
- 목록은 기본으로 **폴더·파일 순**(드라이브와 같은 순서)입니다. 폴더는 파란 굵은 글씨 `📁 이름 /`. 「정렬」에서 위험도·이름·최근 수정 순으로 바꿀 수 있습니다.

## 3. 검사

1. **어디를**: 내 소유 파일 / 나에게 공유된 파일 / 공유 드라이브 / 특정 폴더(폴더 주소 붙여 넣기).
2. **▶ 검사 시작**. 처음은 전체를 검사하고, **두 번째부터는 지난번 이후 바뀐 파일만** 확인해 빠릅니다. 처음부터 하려면 「처음부터 다시」.
3. 앱이 열려 있으면 **1분마다 드라이브 변경 목록만 확인**해서, 브라우저에서 만든 폴더나 바꾼 공유가 저절로 반영됩니다(「설정」에서 끌 수 있음).
4. 검사는 **읽기만** 합니다.

| 노출도 | 뜻 |
|---|---|
| 링크 공개(편집) | 링크만 있으면 누구나 **수정** 가능 |
| 링크 공개(보기) | 링크만 있으면 누구나 볼 수 있음 |
| 외부 계정 공유 | 학교(조직) 밖 계정과 공유 |
| 도메인 공개 | 학교 구성원 누구나 볼 수 있음 |
| 제한됨 | 지정한 사람만 |
| **알 수 없음** | 공유 설정을 볼 권한이 없음 — **안전하다는 뜻이 아닙니다** |

### 파일이 아주 많을 때 (수십만~100만 개 이상)
- **먼저 「링크로 공개된 내 파일만 (빠름)」**으로 검사하세요. 누구나 열 수 있는 파일만 골라 읽어 몇 분이면 끝납니다.
- 「내 소유 파일」 전체 검사는 파일 100만 개에 몇 시간이 걸릴 수 있습니다(구글이 전체 개수를 미리 알려 주지 않아 시간은 진행하면서 보여 줍니다: "구간 7/31 · 1분에 약 6,000개").
- 검사 중에는 **컴퓨터가 저절로 잠들지 않게** 합니다. 노트북 덮개는 열어 두고 전원을 연결하세요.
- **인터넷이 끊기면** 최대 60분 기다렸다가 그 자리부터 이어서 합니다. 앱을 닫았다가 다음 날 다시 열어도 「검사 시작」(「처음부터 다시」 끔)이면 이어서 하고, 오래 쉬었으면 읽던 구간 하나만 다시 읽습니다.
- 드라이브는 검사 중에도 다른 곳에서 그대로 써도 됩니다. 검사는 읽기만 합니다.
- 파일이 5만 개가 넘으면 **자동 반영은 쉽니다**(바뀔 때마다 전체를 다시 분석하면 컴퓨터가 느려지므로). 필요할 때 「검사 시작」을 누르면 바뀐 것만 확인합니다. 진행 줄 오른쪽 「끄기/켜기」로 언제든 바꿀 수 있습니다.

## 4. 개인정보 탐지

- **찾는 항목**: 주민·외국인등록번호, 여권·운전면허번호, 전화번호, 계좌번호(문맥이 있을 때), 카드번호, 이메일, 주소, 학생 명단, 민감정보 의심, 파일명.
- **지원 형식**: 한글(HWP·HWPX), DOCX, XLSX, CSV·TXT, 글자가 있는 PDF, 구글 문서·시트·프레젠테이션.
- **검사 불가**(암호·스캔 PDF·사진·배포용 문서 등)는 **안전하다는 뜻이 아닙니다.** 직접 열어 확인하세요.
- **권장 조치**: 개인정보 × 공유 상태로 판단합니다. 예) 주민번호 + 링크 공개 → "[긴급] 링크 공개 해제", 개인정보 + 나만 봄 → "[유지] … 업무가 끝났으면 암호화 보관 권장". "필요 없음"은 개인정보가 없을 때만.
- **🔍 내용 확인**: 파일 1개를 다시 읽어 위치를 **가린 채로** 보여 줍니다(저장 안 함).
- **🙈 탐지에서 제외**: 잘못 찾은 파일을 다음부터 뺍니다. 되돌리려면 ②의 「🙈 탐지 제외」 칸 → 파일 체크 → **↩ 탐지 제외 해제**(바로 다시 검사). 「🙈 제외 목록」에서도 됩니다.

- **「공유된 파일만」**: 링크·외부 계정·도메인으로 공유된 파일만 내용을 읽습니다. 파일이 많으면 이것부터 하세요.
- 파일이 많거나 처음이면 시작 전에 걸리는 시간·권장 사양(메모리 8GB 이상) 안내가 나오고, 진행 중에는 남은 시간을 보여 줍니다. 중단해도 검사한 파일은 기억해 나머지만 이어서 합니다.

## 5. 공유 설정 바꾸기 (🔗)

1. 파일을 체크하고 **🔗 공유 설정 바꾸기**.
2. 조치는 구글 공유 화면과 같은 이름으로 묶여 있습니다: **일반 액세스**(링크 → 제한됨 등) / **액세스 권한이 있는 사용자**(외부 사용자 액세스 권한 삭제, 편집자 → 뷰어) / **설정 ⚙**(재공유·다운로드 옵션 끄기).
3. 미리보기에서 바뀌는 내용과 **제외 이유**(상위 폴더에서 온 권한, 소유자 권한 등)를 확인하고 **변경 실행**. 50개가 넘으면 확인 문구 입력이 필요합니다.
4. 알림 메일은 보내지 않습니다. 결과 창 또는 **🕘 변경 기록**에서 되돌릴 수 있습니다.

## 6. 암호화 보관 (🔒)과 풀기 (🔓)

**보관** — 업무가 끝난 개인정보 파일을 비밀번호로 잠가 둡니다.
1. 파일을 체크하고 **🔒 암호화 보관**. 둘 곳은 기본 **📍 원래 있던 자리**, "원본 삭제(기본)"가 켜져 있습니다.
2. 원본의 공유를 먼저 해제 → 비밀번호 확인 → 암호화 → **풀어서 원본과 비교** → 드라이브에 올리고 **다시 확인**.
3. 결과 창에서 **✓ 암호화 완료**를 누르면 원본은 휴지통으로, 그 자리에 `보관_날짜_xxxxxxxx.7z`만 남습니다(남길 원본은 체크 해제).

**비밀번호는 어디에?**
- 드라이브·인터넷에는 보내지 않습니다. 기본으로 **이 컴퓨터의 키체인**에 저장됩니다(Mac: 「키체인 접근」 → `drive-privacy-guardian`, Windows: 자격 증명 관리자).
- **🛟 복구 키**(권장): 처음 한 번 35자 복구 키를 만들어 **종이에 보관**하면, 이후 보관 파일의 비밀번호는 모두 이 키로 다시 만들 수 있습니다. 키체인과 비밀번호를 다 잃어도 **풀기 창의 비밀번호 칸에 복구 키를 입력**하면 열립니다. 새 컴퓨터에서는 「설정 → 🛟 복구 키 → 입력」. 메일 초기화 기능은 없습니다(누구도 대신 열 수 없게).
- 복구 키가 유출되면 그 키로 만든 모든 보관 파일이 열립니다. 금고처럼 보관하세요.

**풀기**
1. ②의 **🔐 암호화된 파일** 칸 → 파일 체크 → **🔓 보관 파일 풀기**.
2. 기본은 **드라이브의 같은 폴더에 풀기**: 원래 파일이 돌아오고, 확인이 끝나면 암호 파일은 휴지통으로. "이 컴퓨터에 저장"도 고를 수 있습니다.
3. 파일을 고르지 않고 누르면 이 컴퓨터의 `.7z/.zip` 파일을 고릅니다. 앱 없이 **7-Zip·반디집·Keka**로도 열 수 있습니다.

## 7. 정리

- **📁 폴더로 옮기기**: 목적지를 고르거나 **➕ 새 폴더**를 만들어 옮깁니다. 옮기면 볼 수 있는 사람이 늘어나는 곳(더 넓게 공유된 폴더)으로는 **차단**합니다.
- **🧹 정리 제안·중복**: 분류 제안(일반·내부공유·개인정보보호·암호화보관·파기검토)과 내용이 같은 파일을 보여 줍니다(보기만 함).

## 7-1. 예약 검사 (「⏰ 예약」 또는 「파일 → 예약 검사…」)
- 요일과 시간(예: 매일 22:00~06:00), 범위, 개인정보 찾기 여부를 정하면 **그 시간에 알아서 검사를 시작(이어서)하고, 끝 시간에 멈춥니다.** 다음 예약 때 그 자리부터 이어서 합니다. 큰 드라이브를 며칠에 나눠 검사할 때 좋습니다.
- 다 끝나면 알림으로 결과를 알려 줍니다(알림은 이 컴퓨터 안에서만). 이미 끝난 날 밤에는 다시 하지 않습니다.
- **앱이 켜져 있어야 합니다.** 예약이 켜져 있으면 창을 닫아도 메뉴 막대(윈도: 작업 표시줄 오른쪽)의 ★ 아이콘으로 계속 실행됩니다. 끝내려면 아이콘 → 「종료」 또는 「파일 → 종료」.
- 「컴퓨터에 로그인하면 자동으로 켜기」: 로그인할 때 창 없이 아이콘으로 켜져 예약을 기다립니다. Mac은 앱이 **「응용 프로그램」 폴더**에 있어야 켤 수 있습니다(다운로드 폴더나 디스크 이미지에서 실행하면 안내가 나옵니다).
- 예약 시간 동안은 컴퓨터가 저절로 잠들지 않게 하지만, **잠든 컴퓨터를 깨우지는 못합니다.** 전원을 연결하고 노트북 덮개를 열어 두세요.
- 로그인이 만료되었으면 검사하지 않고 알림만 보냅니다(밤중에 로그인 창을 띄우지 않음). 문제가 생기면 10분 뒤 다시 시도합니다.

## 8. 설정·기록 (「파일 → 설정」)

| 항목 | 설명 |
|---|---|
| 드라이브 변경 자동 반영 | 1분마다 변경 목록만 확인 (기본 켬) |
| 검사 기록 보관 기간 | 7~365일(기본 30일). 지난 기록은 자동 삭제 |
| 🗑 모든 기록 삭제 | 이 컴퓨터의 검사 결과·변경 기록·로그 삭제. 보관 파일 비밀번호·복구 키는 **따로 체크하고 '비밀번호까지 삭제'를 입력해야만** 지워짐 |
| 🛟 복구 키 | 만들기 / 보기·인쇄 / 입력 |
| 내부 도메인 | 학교 도메인을 "외부"로 보지 않게 |
| 앱을 닫을 때 자동 로그아웃 | 공용 PC 권장 |

「도움말 → 보안 점검표」는 구글 계정·NAS·웹호스팅을 **스스로 점검하는 표**입니다. 체크한다고 보안이 강화되지는 않습니다([SERVER_SECURITY_KO.md](SERVER_SECURITY_KO.md)).

## 9. 한계
- "발견되지 않음"은 **지원 범위 안에서** 발견되지 않았다는 뜻입니다.
- 운영체제의 스왑·절전 파일은 앱이 통제할 수 없습니다. 디스크 암호화(FileVault/BitLocker)를 권장합니다.
