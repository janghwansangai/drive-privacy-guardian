# 구글 로그인 설정 안내 (개인 설정, C 방식)

Drive Privacy Guardian은 **여러분이 직접 만든 "로그인 열쇠"(OAuth 클라이언트)** 로 구글에 로그인합니다.
그래서 여러분의 파일과 로그인 정보는 **여러분 PC ↔ 구글** 사이에서만 오가고, 앱 개발자를 포함한 누구에게도 전달되지 않습니다.

- 소요 시간: 약 10~15분 (처음 한 번만)
- 비용: 무료 (결제 정보 등록이 필요 없습니다)
- 학교에서 클라이언트 파일을 받았다면 이 안내는 건너뛰고 [8단계](#8-앱에-불러오기)로 가세요.

> 📷 각 단계의 `[스크린샷]` 표시는 화면 예시가 들어갈 자리입니다.
> 구글 콘솔 화면은 영어로 보일 수 있어 영어 메뉴 이름을 함께 적었습니다.

---

## 1. 구글 클라우드 콘솔 열기

1. 브라우저에서 <https://console.cloud.google.com> 에 접속합니다.
2. 앱에서 사용할 구글 계정으로 로그인합니다.
   - 처음이면 서비스 약관 동의 화면이 나옵니다. 국가를 고르고 동의합니다.

`[스크린샷: 콘솔 첫 화면]`

## 2. 프로젝트 만들기

1. 화면 위쪽의 **프로젝트 선택** (Select a project) → **새 프로젝트** (New project)
2. 프로젝트 이름: `dpg-personal` (아무 이름이나 괜찮습니다) → **만들기** (Create)
3. 만든 프로젝트가 위쪽에 선택되어 있는지 확인합니다.

`[스크린샷: 새 프로젝트 화면]`

> ⚠ 학교 계정에서 "프로젝트를 만들 권한이 없습니다"가 나오면 → [문제 해결](#학교-계정에서-막힐-때)

## 3. Google Drive API 사용 설정

1. 왼쪽 메뉴 → **API 및 서비스** (APIs & Services) → **라이브러리** (Library)
2. 검색창에 `Google Drive API` 입력 → 선택 → **사용** (Enable)

`[스크린샷: Google Drive API 사용 버튼]`

## 4. 앱 정보 입력 (브랜딩)

1. 왼쪽 메뉴 → **Google 인증 플랫폼** (Google Auth Platform) → **브랜딩** (Branding)
   - "아직 구성되지 않았습니다"가 보이면 **시작하기** (Get started)를 누릅니다.
2. 앱 이름: `Drive Privacy Guardian (개인용)`
3. 사용자 지원 이메일: 본인 이메일
4. 개발자 연락처 이메일: 본인 이메일 → 저장

`[스크린샷: 브랜딩 화면]`

## 5. 사용자 유형과 테스트 사용자 (대상)

1. **대상** (Audience) 메뉴 → 사용자 유형 **외부** (External)
   - 개인 gmail 계정은 "외부"만 선택할 수 있습니다. 정상입니다.
2. **테스트 사용자** (Test users) → **사용자 추가** (Add users) → **본인 이메일**을 추가 → 저장

`[스크린샷: 테스트 사용자 추가]`

> 여기에 본인 계정을 추가하지 않으면 로그인할 때 "액세스 차단됨"이 나옵니다.

## 6. (선택) 데이터 액세스

**데이터 액세스** (Data Access) → **범위 추가 또는 삭제** (Add or remove scopes)에서 아래를 추가해 두면 콘솔에서 어떤 권한을 쓰는지 한눈에 볼 수 있습니다. 앱은 필요한 권한을 로그인할 때 단계별로 요청하므로 이 단계를 건너뛰어도 됩니다.

| 범위 | 쓰이는 곳 |
|---|---|
| `.../auth/drive.metadata.readonly` | 권한 감사 (파일 이름·공유 설정 읽기) |
| `.../auth/drive.readonly` | 개인정보 탐지 (파일 내용 읽기) |
| `.../auth/drive` | 권한 변경·암호화 보관 (승인 후에만 사용) |

## 7. 로그인 열쇠(클라이언트) 만들기

1. **클라이언트** (Clients) 메뉴 → **클라이언트 만들기** (Create client)
2. 애플리케이션 유형: **데스크톱 앱** (Desktop app) ← 꼭 이 유형이어야 합니다
3. 이름: `dpg-desktop` → **만들기** (Create)
4. 만들어진 클라이언트의 **JSON 다운로드** (Download JSON)를 눌러 파일을 저장합니다.
   - 파일 이름은 `client_secret_....json` 형태입니다.

`[스크린샷: 데스크톱 앱 선택 / JSON 다운로드]`

> 🔒 이 파일은 여러분 프로젝트의 열쇠입니다. 다른 사람에게 보내거나 공유 드라이브에 올리지 마세요.

## 8. 앱에 불러오기

앱의 첫 실행 화면에서 **"개인 설정(C)"** 또는 **"학교에서 받은 파일이 있음(B)"** 을 고른 뒤 JSON 파일을 선택합니다.
(개발용 CLI: `dpg client import 다운로드한_파일.json`)

- 앱은 파일 내용을 **macOS 키체인 / Windows 자격 증명 관리자**에 저장합니다.
- 불러오기가 끝나면 **원본 JSON 파일을 삭제하고 휴지통도 비워 주세요.** 앱은 더 이상 원본이 필요 없습니다.

## 9. 로그인

앱에서 **로그인**을 누르면 (CLI: `dpg login`) 브라우저가 열립니다.

1. 계정을 선택합니다.
2. **"Google에서 확인하지 않은 앱"** 화면이 나옵니다.
   → **고급** (Advanced) → **(앱 이름)(으)로 이동(안전하지 않음)** 을 누릅니다.
   - 이 경고는 여러분이 직접 만든 앱이 구글의 공개 배포 심사를 받지 않았기 때문에 나옵니다. 본인만 쓰는 앱이라 심사가 필요 없습니다.
3. 권한 화면에서 **모든 항목을 체크**하고 **계속** (Continue)을 누릅니다.
4. "로그인 완료" 페이지가 보이면 브라우저 탭을 닫고 앱으로 돌아갑니다.

`[스크린샷: 확인하지 않은 앱 경고 → 고급 → 이동]`

## 알아 두기: 7일마다 다시 로그인

5단계의 "테스트" 상태에서는 구글 정책상 **로그인이 7일 후 만료**됩니다 (구글 공식 문서 확인, 2026-09-26).
만료되면 앱이 "로그인이 만료되었습니다. 다시 로그인해 주세요."라고 안내합니다. 오류가 아니며 다시 로그인하면 됩니다.

**7일 만료를 없애려면 (선택):** **대상** (Audience) → 게시 상태 **앱 게시** (Publish app)로 "프로덕션"으로 바꿀 수 있습니다.
- 구글 심사를 받지 않은 상태이므로 로그인 때 "확인하지 않은 앱" 경고는 계속 나옵니다.
- 심사 전 앱은 새 사용자 100명 한도가 있지만, 본인만 쓰므로 문제 되지 않습니다.
- 구글은 공개 서비스에는 심사를 권장합니다. 이 방법은 **본인 전용 클라이언트**에만 사용하세요.

## 문제 해결

| 화면에 보이는 문구 | 원인 | 해결 |
|---|---|---|
| 액세스 차단됨 / `access_denied` / "앱이 Google 인증 절차를 완료하지 않았습니다" | 테스트 사용자에 본인 계정이 없음 | 5단계에서 로그인할 계정을 테스트 사용자로 추가 |
| 로그인 화면에 **내가 만든 것이 아닌 앱 이름**이 나오고 액세스 차단됨 | 이 컴퓨터에 예전 열쇠(다른 프로젝트의 클라이언트)가 남아 있음 | 앱 오른쪽 위 **🔁 계정·열쇠 바꾸기**(로그인 화면에서는 **다른 열쇠로 바꾸기**) → 새 JSON 선택 |
| "Google Drive API가 사용 설정되지 않았습니다" | 3단계를 건너뜀 | 3단계 진행 후 1~2분 기다렸다가 다시 로그인 |
| "'웹 애플리케이션' 유형의 클라이언트입니다" | 7단계에서 다른 유형을 고름 | 7단계를 **데스크톱 앱**으로 다시 진행 |
| "서비스 계정 키 파일입니다" | 서비스 계정 키를 받음 | 그 키 파일은 매우 민감합니다. 삭제하고, 콘솔에서 서비스 계정 키도 삭제한 뒤 7단계 진행 |
| `invalid_client` | 클라이언트를 삭제했거나 파일이 손상됨 | 7단계에서 JSON을 다시 내려받아 불러오기 |
| "요청한 권한 중 일부가 허용되지 않았습니다" | 권한 화면에서 체크를 해제함 | 다시 로그인하고 모든 항목을 체크 |
| "로그인이 만료되었습니다" | 7일 만료 또는 계정에서 앱 연결 해제 | 다시 로그인 |
| 브라우저가 안 열림 | 기본 브라우저 설정 문제 | 앱에 표시된 주소를 복사해 브라우저에 붙여 넣기 |

### 학교 계정에서 막힐 때

학교(Workspace) 계정은 관리자 정책 때문에 다음 중 하나가 나타날 수 있습니다.
- 프로젝트를 만들 수 없음
- 로그인 때 "관리자가 이 앱을 차단했습니다" / `admin_policy_enforced`

이 경우 개인 설정(C) 대신 **학교 관리자에게 B 방식(조직 내부 클라이언트)** 을 요청하세요.
관리자용 안내: [ADMIN_SETUP_KO.md](ADMIN_SETUP_KO.md)

## 로그아웃과 권한 해제

- 앱의 **로그아웃**(CLI: `dpg logout`)은 구글에 권한 철회를 요청하고 PC의 로그인 정보를 지웁니다.
- 직접 확인하려면: <https://myaccount.google.com/connections> → 앱 이름 → **액세스 권한 삭제**
