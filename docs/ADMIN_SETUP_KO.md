# 학교 관리자용 설정 안내 (조직 내부 클라이언트, B 방식)

학교 Google Workspace 관리자가 **조직 내부용 OAuth 클라이언트** 하나를 만들어 교직원에게 나눠 주는 방식입니다.

| | 내용 |
|---|---|
| 장점 | 교사는 JSON 파일만 받으면 됨 · 구글 심사 불필요 · 인원 제한 없음 · 7일 만료 없음 |
| 제약 | 같은 Workspace 조직 계정만 로그인 가능 · 관리자 설정 필요 |
| 데이터 흐름 | 각 교사 PC ↔ 구글. 관리자나 앱 개발자의 서버를 거치지 않습니다 |

> 메뉴 이름은 2026-09-26 구글 공식 문서 기준입니다. 한국어 화면에서는 이름이 조금 다를 수 있어 영어 이름을 함께 적었습니다.

---

## 1. 조직 계정으로 Cloud 프로젝트 만들기

1. **학교 조직 계정**으로 <https://console.cloud.google.com> 접속
2. **새 프로젝트** → 이름 `dpg-school` → 조직(학교)이 선택되어 있는지 확인 → 만들기
3. **API 및 서비스** → **라이브러리** → `Google Drive API` → **사용**

## 2. 동의 화면: 사용자 유형 "내부"

1. **Google 인증 플랫폼** (Google Auth Platform) → **브랜딩**: 앱 이름 `Drive Privacy Guardian`, 지원 이메일(학교 정보부 등)
2. **대상** (Audience) → 사용자 유형 **내부** (Internal)
   - 내부 앱은 조직 구성원만 사용할 수 있고, 구글 심사와 테스트 사용자 등록이 필요 없습니다.

## 3. 데스크톱 앱 클라이언트 발급

1. **클라이언트** (Clients) → **클라이언트 만들기** → 유형 **데스크톱 앱** (Desktop app) → 만들기
2. **JSON 다운로드**

## 4. 관리 콘솔에서 앱 신뢰 설정 (필수)

Drive는 구글이 "제한된 서비스"로 분류합니다. 조직의 API 제어 설정에 따라 내부 앱이라도 **신뢰(Trusted)** 로 지정해야 Drive에 접근할 수 있습니다.

1. <https://admin.google.com> → **보안** (Security) → **액세스 및 데이터 제어** (Access and data control) → **API 제어** (API controls)
2. 아래 둘 중 하나를 설정합니다.
   - **내부 앱 신뢰** (Trust internal apps) 설정 켜기 — 조직이 만든 모든 내부 앱이 제한된 API에 접근 가능
   - 또는 **앱 액세스 관리** (Manage App Access)에서 이 앱의 클라이언트 ID를 찾아 **신뢰할 수 있음** (Trusted) 지정 — 권장(이 앱만 허용)

| 접근 수준 | 의미 |
|---|---|
| 신뢰할 수 있음 (Trusted) | 제한된 서비스(Drive 포함)까지 접근 가능 |
| 특정 Google 데이터 (Specific Google data) | 관리자가 지정한 범위만 접근 |
| 제한됨 (Limited) | 제한되지 않은 서비스만 → **Drive 접근 불가** |
| 차단됨 (Blocked) | 모든 서비스 차단 |

> "특정 Google 데이터"로 지정한다면 아래 세 범위를 허용해야 모든 기능이 동작합니다:
> `drive.metadata.readonly`(감사), `drive.readonly`(탐지), `drive`(변경·보관 — 모든 변경은 교사 승인 후에만 실행)

## 5. JSON 배포

- 교직원만 접근할 수 있는 곳(교직원 전용 공유 드라이브 등)에 올립니다.
- 내부 유형이므로 조직 밖 계정은 이 JSON으로 로그인할 수 없습니다.
- 교사에게 안내: 앱 첫 화면에서 **"학교에서 받은 파일이 있음(B)"** 선택 → JSON 선택 → 불러온 뒤 내려받은 사본은 삭제.

## 6. 권장: Workspace DLP 규칙 병행

앱은 교사가 실행할 때만 점검합니다. 조직 차원의 상시 방어선으로 Workspace DLP 규칙을 함께 쓰는 것을 권장합니다.

- **보안** → **액세스 및 데이터 제어** → **데이터 보호** (Data protection) → 규칙 관리
- 예: 주민등록번호 등 사전 정의 탐지기가 걸리는 파일의 **외부 공유 차단**
- 에디션별 제공 범위는 관리 콘솔에서 확인하세요 (SPEC V16).

| 증상 | 확인할 것 |
|---|---|
| 교사 로그인 시 "관리자가 이 앱을 차단했습니다" / `admin_policy_enforced` | 4단계 신뢰 설정 |
| 조직 밖 계정으로 로그인 시도 시 차단 | 정상 동작(내부 앱) |

| 클라이언트 JSON이 외부로 유출됨 | 콘솔에서 해당 클라이언트 삭제 후 새로 발급·재배포 (내부 앱이라 외부인은 로그인 불가하지만 교체 권장) |
