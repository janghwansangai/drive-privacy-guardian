# 크롬 확장 프로그램 「Drive Privacy Guardian 뷰어」 설치·사용

데스크톱 앱으로 암호화한 파일(`보관_날짜_xxxxxxxx.7z/.zip`)을 앱 없이 **크롬에서 바로 풀어 봅니다.**
풀린 내용은 **확장 프로그램 창의 메모리에만** 있고 파일로 저장하지 않습니다. 창을 닫거나 10분 동안 쓰지 않으면 지워집니다.

## 바로 볼 수 있는 형식 (현재)
한글(HWP·HWPX), 엑셀(XLSX), CSV, TXT — 한글 뷰어는 **내용 확인용**이라 쪽 모양·그림은 원본과 다를 수 있습니다.
다른 형식(PDF·사진·워드)과 "저장"·"다시 암호화"는 다음 단계에서 추가됩니다. 그전에는 데스크톱 앱의 「🔓 보관 파일 풀기」를 쓰세요.

## 1. 구글 설정 (한 번)
E0 시험 때 만든 **「DPG 확장 프로그램」(웹 애플리케이션) 클라이언트를 그대로** 씁니다(확장 프로그램 ID가 같습니다).
처음이라면: 구글 콘솔(데스크톱 앱과 같은 프로젝트) → 사용자 인증 정보 → **OAuth 클라이언트 ID → 웹 애플리케이션** → 승인된 리디렉션 URI에
```
https://gjlomabldjleleakkeffjojhjdgeekgj.chromiumapp.org/
```
→ 만들기 → **클라이언트 ID**만 복사 (보안 비밀번호는 쓰지 않음).

## 2. 설치 (무료, 개발자 모드)
1. GitHub Releases에서 `DrivePrivacyGuardian-Extension-버전.zip`을 받아 **압축을 풉니다.**
   (개발 중에는 저장소의 `extension/app` 폴더를 그대로 써도 됩니다)
2. 크롬 주소창 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** → 풀린 `DrivePrivacyGuardian-Extension` 폴더 선택
4. ID가 **`gjlomabldjleleakkeffjojhjdgeekgj`**인지 확인. E0 시험용 확장 프로그램이 남아 있으면 먼저 **삭제**하세요(ID가 같아 함께 설치할 수 없습니다).
5. 🧩 퍼즐 아이콘 → 「Drive Privacy Guardian 뷰어」 옆 📌로 고정하면 편합니다.

알아 둘 점: 크롬이 가끔 "개발자 모드 확장 프로그램" 알림을 띄울 수 있습니다(무시해도 됨). **학교 관리 PC**는 개발자 모드가 막혀 있을 수 있습니다 — 그때는 데스크톱 앱을 쓰세요.

## 3. 사용
1. **구글 드라이브를 연 채로** 도구 모음의 확장 프로그램 아이콘을 누르면, 드라이브 **오른쪽에 패널**이 열립니다(같은 창, 새 탭 없음). 패널 가장자리를 끌어 넓힐 수 있고, 아이콘을 다시 누르면 닫힙니다.
   - 드라이브에서 **폴더를 열면** 패널의 「📁 이 폴더」에 그 폴더의 암호화 파일이 보입니다. 「전체」는 모든 암호화 파일.
   - 드라이브에서 파일을 **선택**하면 패널 위쪽 「드라이브에서 선택」 카드에 보입니다. 암호화 파일은 **열기**, 일반 파일은 **🔒 선택한 파일 암호화**.
   - 드라이브에서 암호화 파일을 **더블클릭**하면 드라이브 미리보기처럼 **화면 전체에 크게** 열립니다. ✕ 또는 Esc로 닫습니다. 패널에서 연 파일도 **⛶ 크게 보기**로 크게 볼 수 있습니다.
   - **폴더**도 고를 수 있습니다. 폴더 안 모든 파일이 폴더 구조 그대로 **압축 없이** 암호화 파일 하나로 들어가고(3000개·700MB까지), 풀면 같은 폴더가 다시 생깁니다.
   - **👥 공유 권한 보기·바꾸기**: 고른 파일·폴더를 누가 볼 수 있는지(링크 공개·외부 계정 등) 보여 주고, 데스크톱 앱과 같은 조치(모두 제한됨, 외부 사용자 삭제 등)를 할 수 있습니다. 알림 메일 없음, 바로 「↩ 되돌리기」 가능. 폴더는 「폴더 안 파일까지 조사」.
   - 암호화 파일 목록은 위쪽 **☰** 버튼을 눌렀을 때만 보입니다.
   - 「암호화하기」를 처음 누르면 구글이 **드라이브 파일 보기·수정 권한**을 묻습니다(데스크톱 앱과 같은 권한). 보기만 할 때는 묻지 않습니다. 암호화 → 풀어서 비교 → 같은 폴더에 올리기 → 다시 받아 비교 → 원래 파일을 휴지통으로(기본 켬).
   - 넓게 보고 싶으면 패널 위쪽 **↗**(새 탭에서 크게 보기).
2. 처음 한 번: **⚙ 설정**에 클라이언트 ID를 붙여 넣고 **저장**
   - 그리고 패널 위쪽 **🛟 처음 한 번 설정**: 복구 키(데스크톱 앱에서 만든 35자, 없으면 「새로 만들기」)와 **개인 비밀번호**를 정합니다.
   - 이후에는 **개인 비밀번호 한 번**이면 모든 암호화 파일이 바로 열립니다. **15분** 동안 안 쓰면 자동으로 잠기고(⚙에서 5·15·30·60분), 브라우저를 닫아도 잠깁니다.
   - 비밀번호를 잊으면 **「비밀번호를 잊었나요?」 → 복구 키** → 새 비밀번호.
3. **구글 로그인** → 계정 선택 → 'Google에서 확인하지 않은 앱' **「계속」** → 권한 체크 **「계속」**
   - 요청 권한은 **drive.file**(이 앱이 만들거나 연 파일만)입니다. 드라이브 전체를 보지 않습니다.
4. 목록에서 파일을 누르면 바로 열립니다(잠겨 있으면 개인 비밀번호를 한 번 묻습니다). 복구 키로 잠그지 않은 예전 파일만 "이 파일만의 비밀번호"를 묻습니다.
   - **🔓 풀어서 드라이브에 저장**: 원래 이름으로 같은 폴더에 풀고, 확인 뒤 암호화 파일은 휴지통으로(기본 켬).
   - 암호화 파일 이름은 `상담기록.hwp (암호화 7f3a9c2e).7z`처럼 원래 이름이 보입니다.
5. 파일을 열면 패널이 그 파일 화면으로 바뀝니다. **← 목록**으로 돌아가고, **✕**로 닫으면 메모리에서 지워집니다. 위쪽 파일 이름 단추로 안의 파일을 바꿔 봅니다. 엑셀은 시트 탭이 있습니다.
   - 바로 볼 수 있는 형식: **한글(HWP·HWPX), 엑셀(XLSX), 워드(DOCX), PDF, 사진(PNG·JPG·GIF·WEBP·BMP), CSV·TXT**
   - 그 밖의 형식이나 암호가 걸린 문서는 「💾 이 파일 저장」 후 해당 프로그램으로 여세요.
6. **💾 이 파일 저장**: 지금 보는 파일을 암호 없이 **다운로드 폴더**에 저장합니다. 경고 창에서 「저장」을 눌러야만 저장됩니다. 다 쓰면 휴지통에 버리고 휴지통도 비우세요.
7. 다 보면 **닫기 (메모리에서 지우기)** — 탭을 닫아도 지워집니다.

## 4. 고친 파일을 다시 암호화해 올리기
1. 보관 파일을 열고 **💾 저장**으로 꺼낸 파일을 한글·엑셀 등으로 고쳐 저장합니다.
2. 확장 프로그램에서 같은 보관 파일을 연 채로 **🔒 고친 파일로 다시 암호화**를 누릅니다.
3. **파일 선택**으로 고친 파일을 고릅니다. 이름이 같은 파일은 **바꿈**, 새 이름은 **추가**로 표시됩니다. 뺄 파일은 체크합니다.
4. **🔒 암호화해서 드라이브에 올리기** → 암호화 → **다시 풀어서 비교** → 올리기 → **올린 파일을 다시 받아 비교** 순서로 진행됩니다.
   - 비밀번호: 복구 키로 연 파일은 복구 키로 새 비밀번호를 만들고, 비밀번호로 연 파일은 같은 비밀번호를 씁니다. 데스크톱 앱에서도 똑같이 열립니다.
   - 새 파일은 예전 파일과 **같은 폴더**에 올라갑니다(권한이 없으면 내 드라이브 맨 위).
   - 「예전 보관 파일을 휴지통으로」(기본 켬)는 **두 번의 확인이 모두 성공했을 때만** 합니다. 영구 삭제는 하지 않습니다.
5. 끝나면 컴퓨터에 남은 **고친 파일(암호 없음)은 휴지통에 버리고 비우세요.**

**➕ 새 파일 암호화해 올리기**(왼쪽 위): 보관 파일 없이 컴퓨터의 파일을 바로 암호화해 **내 드라이브 맨 위**에 올립니다. 비밀번호 칸에 **복구 키**를 넣는 것을 권장합니다(직접 정한 비밀번호는 어디에도 저장되지 않아, 잊으면 열 수 없습니다).

## 5. 안전에 관해
- 확장 프로그램은 **구글 드라이브 API 주소에만** 접속하도록 크롬 보안 정책(CSP)으로 막혀 있고, 원격 코드·분석·오류 보고가 없습니다.
- 확장 프로그램이 저장하는 것은 **클라이언트 ID**(비밀 아님)뿐입니다. 비밀번호·복구 키는 저장하지 않고, 파일 내용은 「💾 저장」을 눌렀을 때만 다운로드 폴더에 저장됩니다.
- 다른 확장 프로그램이나 웹페이지는 이 창의 내용을 읽을 수 없습니다.
- 한계: 운영체제의 스왑·화면 캡처는 막을 수 없습니다.
