# 계정·서버 보안 점검표

앱의 「도움말 → 보안 점검표」와 같은 내용입니다. **스스로 점검해 보는 표**이며, 각 설정은 해당 관리 화면에서 직접 바꿔야 합니다.

> ⚠ 앱에서 체크 표시를 한다고 보안이 강화되지는 않습니다. 체크는 "내가 확인했음"을 기억해 두는 메모일 뿐이고, 앱은 실제 설정을 확인하거나 바꾸지 않습니다. 앱은 이 점검표를 위해 인터넷에 접속하지 않으며, 체크한 항목은 이 컴퓨터에만 저장됩니다.

## 1. 구글 계정

| 항목 | 방법 |
|---|---|
| 2단계 인증·패스키 | 구글 계정 → 보안 → 2단계 인증, 패스키 켜기 (https://myaccount.google.com/security) |
| 연결된 타사 앱 정기 점검 | 학기마다 구글 계정 → 보안 → 타사 앱 및 서비스에서 쓰지 않는 앱 삭제 (https://myaccount.google.com/connections). 이 앱을 더 쓰지 않으면 여기서도 삭제하세요. |
| 업무 자료는 공유 드라이브 | 담당자가 바뀌어도 자료가 남고, 권한을 드라이브 단위로 관리할 수 있습니다. |
| 전보·퇴직 시 소유권 이전 | 개인 드라이브의 업무 파일은 후임자 또는 공유 드라이브로 옮기고, 개인정보 파일은 보존 기한을 확인해 파기합니다. |
| Workspace DLP 규칙 요청 | 학교 관리자에게 주민등록번호 등이 든 파일의 외부 공유를 막는 DLP 규칙을 요청합니다(에디션에 따라 제공 여부가 다름). |
| 클라이언트 측 암호화(CSE) | Education Standard·Education Plus 등 일부 에디션에서만 제공되며 관리자 설정이 필요합니다. CSE로 암호화된 파일은 이 앱이 내용을 검사할 수 없습니다(`검사 불가`). |

## 2. 시놀로지 NAS

| 항목 | 방법 |
|---|---|
| 기본 admin 비활성화 | 새 관리자 계정을 만든 뒤 admin 계정을 끕니다. |
| 2단계 인증 | 제어판 → 보안 → 계정 |
| 자동 차단 | 로그인 실패가 반복되는 IP 자동 차단 |
| 방화벽 | 필요한 포트와 내부망만 허용 |
| 포트 포워딩 최소화 | 관리 포트를 인터넷에 직접 열지 말고, 외부 접속은 VPN(Tailscale 등)으로 |
| 공유 폴더 암호화 | 개인정보가 있는 공유 폴더는 암호화 |
| 스냅샷 | 정기 스냅샷, 가능하면 변경 불가(immutable) 스냅샷 |
| 오프라인 외장 백업 | 3-2-1 원칙: 사본 3개, 매체 2종, 1개는 분리 보관 |
| 정기 복원 시험 | 백업에서 실제로 파일을 되살려 봅니다 |

## 3. 웹호스팅 (cPanel)

| 항목 | 방법 |
|---|---|
| 공개 폴더에 개인정보 금지 | `public_html` 아래 명단·신청서 파일 확인 후 삭제 |
| 디렉터리 목록 차단 | Directory Privacy / Indexes에서 목록 표시 끄기 |
| 관리자 페이지 접근 제한 | IP 제한 또는 추가 비밀번호 |
| 2단계 인증 | Security → Two-Factor Authentication |
| SSL | 모든 페이지 https로만 |
| 백업 확인 | 호스팅 백업 주기와 복원 방법 확인 |
