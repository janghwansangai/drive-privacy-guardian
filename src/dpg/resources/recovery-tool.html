비밀번호 복구 도구

프로그램이 없어도, 종이에 적어 둔 복구 키와 암호화 파일의 이름만 있으면 그 파일의 비밀번호를 다시 만듭니다. 이 페이지는 인터넷에 연결하지 않으며 아무것도 저장하지 않습니다(이 파일만 있으면 오프라인에서도 동작).

기본 ZIP이면 이 도구가 필요 없습니다. 기본 ZIP으로 암호화한 파일(….zip)은 윈도우·맥에서 두 번 누르고 공통 비밀번호(처음 암호화할 때 정해 종이에 적어 둔 것)만 넣으면 열립니다. 이 도구는 높은 보안 7z와 복구 키로 만든 예전 파일용입니다.

띄어쓰기·하이픈·소문자는 상관없습니다. 0/O, 1/I, 8/B도 자동으로 맞춥니다.

구글 드라이브에서 파일 이름을 그대로 복사해 붙여 넣으세요. 괄호 안 8자(예: 7f3a9c2e)만 넣어도 됩니다.

하이픈(-)까지 포함해 그대로 넣으세요.

.zip 파일입니다. 기본 ZIP이면 이 비밀번호가 아니라 공통 비밀번호로 열립니다. 이 비밀번호는 복구 키로 만든 예전 ZIP용입니다.

3. 압축 프로그램으로 열기
  1. Windows: 무료 7-Zip 설치 → 파일 오른쪽 클릭 → 7-Zip → 압축 풀기 → 비밀번호 붙여 넣기
  2. Mac: 무료 Keka 또는 The Unarchiver → 파일 열기 → 비밀번호 붙여 넣기 (기본 「아카이브 유틸리티」는 암호화된 7z를 열지 못합니다)
  3. 복구 키로 만든 예전 .zip도 7-Zip·Keka로 같은 방법으로 엽니다.

복구 키가 있으면 이 키로 만든 모든 암호화 파일을 열 수 있습니다. 비밀번호를 다른 사람에게 보내거나 사진으로 남기지 마세요. 다 쓰면 「지우기」를 누르고 창을 닫으세요.
